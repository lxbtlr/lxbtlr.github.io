As the first project of my Scientific Computing course, I created an agent based model to replicate the results of Watmough and Edelstein-Keshet's [*Modelling the Formation of Trail Networks by Foraging Ants*](https://doi.org/10.1006/jtbi.1995.0205) (Journal of Theoretical Biology, 1995).
This project provided a great entry point into the realm of agent based modeling, and strengthened my confidence in replicating scientific coding works.
